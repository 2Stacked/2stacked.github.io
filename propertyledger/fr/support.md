## Nous joindre

Écrivez à [{{ site.contact_email }}](mailto:{{ site.contact_email }}). Indiquez si possible la version d'iOS de
votre iPhone, la version de l'app (onglet Réglages › À propos › Version) et ce que vous faisiez quand le problème
est survenu.

## Questions fréquentes

### Mes données sont-elles sauvegardées?

Vos fiches font partie de la sauvegarde de votre iPhone (sauvegarde iCloud ou sauvegarde sur ordinateur). Si vous
activez Utiliser iCloud dans l'onglet Réglages de l'app, elles sont aussi conservées dans votre base de données
iCloud privée.

### Comment passer à un nouvel iPhone?

Activez Utiliser iCloud dans l'onglet Réglages de l'app avant de changer d'appareil. Le changement s'applique à la
prochaine ouverture de l'app. Vos fiches apparaîtront ensuite sur le nouvel iPhone dès que vous vous connecterez au
même compte Apple. Restaurer le nouvel iPhone à partir d'une sauvegarde de l'ancien les transfère aussi.

### Comment partager le dossier de ma maison?

Dans l'onglet Accueil, touchez le nom de votre maison en haut pour ouvrir À propos de ce logement, puis touchez
Partager le rapport sur le logement. Vous pouvez choisir ce qui figure dans le rapport avant de partager le PDF.

### Comment tout supprimer?

Voir [Supprimer vos données](/propertyledger/fr/privacy/#supprimer-vos-donnees) dans la politique de
confidentialité.
